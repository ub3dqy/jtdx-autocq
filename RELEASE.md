# AutoCQ 0.9.36

## Русский

- Для «Южного Казахстана» программа определяет нужные области по первой букве после цифры в позывном. Учитываются отдельные ставки для станций из положения и двойные очки на 160 м и УКВ.
- Для двух серий ARCK QSO подходят станции всех стран. AutoCQ показывает ближайшую степень по зачёту HAMLOG и учитывает повторную связь с той же станцией на другом диапазоне или другим видом работы.
- Добавлен поиск для пяти дипломов RCPW, среди них «Морчасти ПВ», «Пограничные войска» и «Отличник погранвойск». Позывные берутся из списка клуба. Для дипломов за разных членов клуба достаточно одной связи с каждым участником.
- Если положения уже скачаны, откройте **«Дипломы HAMLOG»** и нажмите **«Разобрать скачанное»**, чтобы применить новые правила.

**Как обновиться.** Откройте **«Обновления»**, скачайте выпуск и закройте JTDX перед установкой. Затем нажмите **«Обновить и перезапустить»**. При работе с LogHX запускайте JTDX значком в журнале.

## English

- For South Kazakhstan, AutoCQ uses the first letter after the digit in the callsign to find eligible regions. It also applies the listed callsign bonuses and doubles points on 160 m and VHF.
- Both ARCK QSO series accept stations from any country. AutoCQ shows the next tier from HAMLOG and counts repeat contacts on a different band or in a different mode group.
- Added search rules for five RCPW awards, including Marine Units of the Border Troops, Border Troops and Excellence in Border Troops. AutoCQ uses the club roster. When an award calls for different club members, one contact with each member counts.
- If you have already downloaded the conditions, open **«Дипломы HAMLOG»** (HAMLOG awards) and click **«Разобрать скачанное»** (Process downloaded rules) to apply the new rules.

**Updating.** Open **«Обновления»** (Updates), download the release, and close JTDX before installation. Click **«Обновить и перезапустить»** (Update and restart). If you use LogHX, launch JTDX from its icon.
